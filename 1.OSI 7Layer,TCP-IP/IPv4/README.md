## IPv4 헤더의 주요 정보

1. **버전 (Version)**: 현재 사용 중인 IP 프로토콜의 버전입니다. IPv4이므로 숫자 '4'가 들어간다.
2. **헤더 길이 (Header Length)**: IPv4 헤더 자체의 크기입니다. '옵션' 필드 유무에 따라 헤더 길이가 변할 수 있으므로 이 정보가 필요하다.
3. **서비스 유형 (Type of Service, ToS)**: 패킷의 우선순위나 요구되는 서비스 품질(QoS)을 라우터에 알려준다. (예: 지연 시간 최소화, 처리량 극대화 등)
4. **전체 길이 (Total Length)**: 헤더와 실제 데이터를 모두 합친 패킷의 전체 길이다.
5. **식별자 (Identification)**: 패킷에 할당된 고유 번호입니다. 데이터가 커서 단편화(쪼개짐)될 때, 조각들이 원래 같은 데이터에서 나왔음을 증명한다.
6. **플래그 (Flags)**: 패킷의 단편화 여부, 혹은 더 이상 쪼개면 안 되는지 등 조각화 제어 상태를 나타낸다.
7. **단편화 오프셋 (Fragment Offset)**: 쪼개진 패킷들이 목적지에서 재조립될 때, 원래 데이터의 어느 위치(순서)에 들어가야 하는지 알려준다.
8. **TTL (Time To Live, TTL)**: 패킷이 네트워크를 무한정 떠도는 것을 막기 위한 수명 값입니다. 라우터를 거칠 때마다 1씩 줄어들며, 0이 되면 즉시 폐기된다.
9. **프로토콜 (Protocol)**: 상위 계층(전송 계층)에서 어떤 프로토콜을 사용하는지 명시합니다. 대표적으로 TCP(6) 또는 UDP(17)가 들어간다.
10. **헤더 체크섬 (Header Checksum)**: 전송 과정에서 헤더 정보에 오류나 손상이 발생했는지 검사하기 위한 확인 값이다.
11. **출발지 IP 주소 (Source IP Address)**: 패킷을 처음 만들어 보낸 송신자의 IP 주소이다.
12. **도착지 IP 주소 (Destination IP Address)**: 패킷이 최종적으로 도착해야 할 수신자의 IP 주소이다.
13. **옵션 및 패딩 (Options & Padding)**: 보안, 라우팅 경로 기록 등 특수 목적을 위한 '옵션'과, 헤더 크기를 32비트 단위로 맞추기 위해 채워 넣는 의미 없는 0의 연속인 '패딩'으로 구성된다.

## ARP

IP 주소를 통해 MAC주소를 알아내는 프로토콜이다.<BR>
동일 네트워크내에 있는 송수신 대상의 IP 주소를 알아낼 수 있다.<BR>
