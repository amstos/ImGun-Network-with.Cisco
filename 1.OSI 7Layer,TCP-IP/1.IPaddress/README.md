# IP Address

## 개요

IP Address(Internet Protocol Address)는 네트워크 상에서 장치를 식별하기 위한 논리적 주소이다.

OSI 7계층의 Network Layer(Layer 3)에서 사용되며, 데이터를 목적지까지 전달하기 위한 주소 체계 역할을 수행한다.

---

## IP Address란?

- IP (Internet Protocol) : 네트워크 상에서 각 장치에 부여되는 고유한 주소

- IPv4 : 32비트 주소 체계 → 약 43억 개 주소.  IPv6는 128비트로 거의 무한대.

- 표현 형태 : 4개의 8비트(Octet)씩 10진수로 표시하고 ‘.’으로 구분함

- 32개의 비트를 네트워크 비트와 호스트비트로 구분함.

- 네트워크비트와 호스트비트를 구분하기 위해 서브넷마스크를 사용함.

- 클래스개념을 사용해 기본 서브넷마스크로 네트워크를 구분함.


### IPv4 예시

```text
192.168.10.100
```

### IPv6 예시

```text
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

---

## IPv4 구조

IPv4는 32비트로 구성된다.

```text
192.168.10.100

11000000.10101000.00001010.01100100
```

IPv4 주소는 8비트씩 총 4개의 옥텟(Octet)으로 구성된다.

```text
8bit + 8bit + 8bit + 8bit = 32bit
```

---

## Network ID와 Host ID

IP 주소는 Network ID와 Host ID로 구분된다.

```text
192.168.10.100/24

Network ID : 192.168.10
Host ID    : 100
```

### 역할

* Network ID : 어떤 네트워크인지 식별
* Host ID : 네트워크 내부의 장비 식별

---

## IPv4 클래스

초기 IPv4는 클래스 기반 주소 체계를 사용하였다.

| Class | 시작 범위     | 기본 서브넷 마스크          |
| ----- | --------- | ------------------- |
| A     | 1 ~ 126   | 255.0.0.0 (/8)      |
| B     | 128 ~ 191 | 255.255.0.0 (/16)   |
| C     | 192 ~ 223 | 255.255.255.0 (/24) |
| D     | 224 ~ 239 | Multicast           |
| E     | 240 ~ 255 | Reserved            |

---

## 클래스별 예시

### Class A

```text
10.1.1.1
```

### Class B

```text
172.16.1.1
```

### Class C

```text
192.168.1.1
```

---

## 공인 IP와 사설 IP

### 공인 IP (Public IP)

인터넷에서 사용 가능한 IP 주소

* ISP가 할당
* 전 세계에서 유일

예시

```text
8.8.8.8
1.1.1.1
```

---

### 사설 IP (Private IP)

내부 네트워크에서 사용되는 주소

인터넷에서는 직접 사용 불가능하며 NAT가 필요하다.

| 대역      | 범위                            |
| ------- | ----------------------------- |
| Class A | 10.0.0.0 ~ 10.255.255.255     |
| Class B | 172.16.0.0 ~ 172.31.255.255   |
| Class C | 192.168.0.0 ~ 192.168.255.255 |

---

## 특수 IP 주소

### 네트워크 주소

Host 비트가 모두 0

```text
192.168.10.0/24
```

---

### 브로드캐스트 주소

Host 비트가 모두 1

```text
192.168.10.255/24
```

---

### 루프백 주소

자기 자신을 가리키는 주소

```text
127.0.0.1
```

---

### APIPA

DHCP 서버가 없을 경우 자동 할당

```text
169.254.0.0/16
```

---

## 기본 게이트웨이(Default Gateway)

다른 네트워크로 이동하기 위한 출구 역할을 한다.

일반적으로 라우터 인터페이스 주소를 사용한다.

예시

```text
PC
IP : 192.168.10.100
Mask : 255.255.255.0
Gateway : 192.168.10.1
```

---

## 데이터 전송 예시

```text
PC1
192.168.10.100
        │
        ▼
Default Gateway
192.168.10.1
        │
        ▼
Internet
```

같은 네트워크는 직접 통신하고,

다른 네트워크는 기본 게이트웨이를 통해 통신한다.
