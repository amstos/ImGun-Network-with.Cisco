# Static, Dynamic IP

## 개요
호스트에 IP를 할당하는 방법은 크게 정적IP와 동적IP가 있다.
전자는 직업 호스트에 입력하는 방식이고 후자는 일반적으로 DHCP를 이용하여 서버, 라우터를 통해 이루어진다.

---

### 1. 정적 IP 할당 (Static IP Allocation)
네트워크 관리자나 사용자가 기기에 IP 주소를 **수동으로 직접 입력하여 고정**시키는 방식입니다. 한 번 설정된 IP 주소는 임의로 변경하지 않는 한 계속 유지됩니다.

* **장점**
  * **안정성:** IP 주소가 변하지 않으므로 외부에서 접속하기가 매우 안정적입니다.
  * **서버 운영에 적합:** 웹 서버, 메일 서버, CCTV, 네트워크 프린터 등 항상 같은 주소로 접근해야 하는 장비에 필수적입니다.
* **단점**
  * **비효율적인 자원 관리:** 기기가 전원이 꺼져 있어도 해당 IP를 다른 기기가 사용할 수 없어 IP 주소가 낭비될 수 있습니다.
  * **관리의 어려움:** 수동으로 할당하다 보니 실수로 다른 기기와 IP 주소가 중복(IP 충돌)되는 문제가 발생할 수 있습니다.

---

### 2. 동적 IP 할당 (Dynamic IP Allocation)
기기가 네트워크에 연결될 때마다 라우터(공유기) 또는 서버의 **DHCP(Dynamic Host Configuration Protocol) 서버가 자동으로 IP 주소를 할당(임대)** 해주는 방식입니다.

* **장점**
  * **효율적인 IP 사용:** 한정된 IP 주소 풀(Pool) 내에서 현재 네트워크를 사용하는 기기에게만 IP를 빌려주므로 자원 활용도가 높습니다.
  * **편리한 관리:** 사용자가 직접 네트워크 설정을 할 필요가 없고, IP 충돌 문제를 DHCP 서버가 알아서 방지해 줍니다. (스마트폰이나 노트북이 와이파이에 연결될 때 바로 인터넷이 되는 이유입니다.)
* **단점**
  * **주소 변동성:** 일정 시간(임대 시간)이 지나거나 기기를 재부팅하면 IP 주소가 바뀔 수 있어, 외부에서 지속적으로 접속해야 하는 서버용으로는 부적합합니다.
  * **의존성:** DHCP 서버에 문제가 생기면 네트워크 내 기기들이 IP를 할당받지 못해 통신이 단절될 수 있습니다.
